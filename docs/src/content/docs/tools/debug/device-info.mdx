## Overview

Retrieve comprehensive device details including model, manufacturer, Android version, API level, screen density, resolution, and available storage.

<Aside type="note">
  Returns structured output (`model`, `manufacturer`, `androidVersion`, `sdkLevel`, `cpuAbi`, `screenDensity`, `buildId`, `buildType`, `hardware`, `heapSize`, `batteryLevel`, `screenResolution`) alongside the human-readable summary, so clients can consume it programmatically.
</Aside>

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `deviceId` | `string` | No | — | Target device serial |

## Examples

> Get info about my connected device

> Show device model, OS version, and screen density
