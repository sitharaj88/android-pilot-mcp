## Overview

Record the device screen and save it as an MP4 file locally. Useful for capturing bug reproductions and creating demos.

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `savePath` | `string` | Yes | — | Local path to save the MP4 recording |
| `duration` | `number` | No | `10` | Recording duration in seconds (clamped to 1-180) |
| `deviceId` | `string` | No | — | Target device serial |

## Examples

> Record my device screen for 30 seconds

> Record a 10-second video and save to ./recording.mp4

> Record the screen for 60 seconds and save to ~/Desktop/demo.mp4

<Aside type="note">
  The `duration` parameter is validated and clamped to 1-180 seconds (3 minutes) by the server — a request outside that range is rejected before any recording starts. Each recording is written to a unique temporary file on the device and cleaned up automatically once it's pulled to your local machine.
</Aside>
