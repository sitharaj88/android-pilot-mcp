## Overview

Wipe all app data including databases, shared preferences, and cache. The app will behave as if freshly installed.

<Aside type="caution">
  This is a destructive operation. On MCP clients that support elicitation, the server asks for confirmation before clearing data. On clients that don't support elicitation, it proceeds without prompting.
</Aside>

## Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `packageName` | `string` | Yes | — | Application package name |
| `deviceId` | `string` | No | — | Target device serial |

## Examples

> Clear all data for com.example.myapp

> Reset my app to fresh state
