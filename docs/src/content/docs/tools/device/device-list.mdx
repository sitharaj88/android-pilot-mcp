## Overview

Show all connected physical devices and running emulators with their serial numbers and connection status.

<Aside type="note">
  Returns structured output (a `devices` array with `id`, `state`, `type`, and `model`) alongside the human-readable summary, so clients can consume it programmatically.
</Aside>

## Parameters

No parameters required.

## Examples

> List my connected Android devices

> Show all connected devices and emulators
